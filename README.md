# lusbeauty — Lush Beauty Mart Nagpur

> **“Where Beauty Meets Quality”**

A modern, premium, mobile-first e-commerce web application for **Lush Beauty Mart**, a retail and wholesale destination in Nagpur offering skincare products, cosmetics, artificial jewellery, handbags, beauty accessories, and fashion accessories.

## ✨ Features
- **Brand Aesthetic**: Warm cream/ivory palette, dark chocolate brown typography, subtle gold accents, Playfair Display serif headings, Plus Jakarta Sans body.
- **Nagpur Store Showcase**: Interactive Google Maps location card, Metro pillar landmarks, 1-click call, WhatsApp enquiry, and in-store pickup options.
- **6 Comprehensive Categories**: Skincare, Cosmetics, Artificial Jewellery, Handbags, Beauty Accessories, Fashion Accessories.
- **E-Commerce & WhatsApp Commerce**: Slide-out cart, live coupon discounts (`LUSH30`, `BOGO`, `JEWEL25`), 1-click WhatsApp order generation, and printable invoice receipts.
- **Wholesale Portal**: Dedicated B2B bulk inquiry portal for salon owners and boutique retailers.
- **Dynamic Admin Suite**: Product manager with image preview, price/discount configuration, stock toggling, offer creator, and order logs.

---

## 🚀 Tech Stack
- **Frontend**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS with custom luxury color tokens
- **Icons**: Lucide React
- **Confetti**: Canvas Confetti

## 💻 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm / yarn / pnpm

### Installation
```bash
# Clone the repository
git clone https://github.com/8dbluetick/lusbeauty.git

# Navigate into directory
cd lusbeauty

# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
